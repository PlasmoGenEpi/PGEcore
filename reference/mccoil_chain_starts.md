# Starting COI for each McCOIL chain

Starting COI for each McCOIL chain

## Usage

``` r
mccoil_chain_starts(M0, n_chains, maxCOI)
```

## Arguments

- M0:

  One starting COI for every chain, or one per chain, as a numeric
  vector or a comma-separated string such as `"1,5,15"`.

- n_chains:

  Number of chains.

- maxCOI:

  Upper bound for COI.

## Value

Integer vector with one starting COI per chain.
