# Whether a VCF should be (re)converted to GDS

Whether a VCF should be (re)converted to GDS

## Usage

``` r
gds_needs_conversion(vcf_path, gds_path, overwrite = FALSE)
```

## Arguments

- vcf_path:

  Input VCF path.

- gds_path:

  GDS path.

- overwrite:

  If `TRUE`, always convert.

## Value

Logical.
