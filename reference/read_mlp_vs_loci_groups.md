# Read loci-group definitions for variantstring multilocus prev/freq

Read loci-group definitions for variantstring multilocus prev/freq

## Usage

``` r
read_mlp_vs_loci_groups(loci_groups_path)
```

## Arguments

- loci_groups_path:

  Path to a TSV with `group_id`, `gene_id`, `aa_position`.

## Value

A tibble of loci groups.
