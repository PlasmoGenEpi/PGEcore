# Run Dcifer with population-specific allele frequencies

Run Dcifer with population-specific allele frequencies

## Usage

``` r
run_dcifer_bypop(
  allele_table_path,
  coi,
  specimen_metadata,
  specimen_name_col = "specimen_name",
  target_name_col = "target_name",
  target_value_col = "seq",
  use_estm = FALSE,
  ...
)
```
