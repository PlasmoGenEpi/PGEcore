# Decompose shared and unique values between two vectors

Decompose shared and unique values between two vectors

## Usage

``` r
set_decompose(vector_a, vector_b)
```

## Arguments

- vector_a:

  First vector.

- vector_b:

  Second vector.

## Value

A list with `only_in_vector_a`, `only_in_vector_b`, `shared`, and `all`.
