# Require variantstring 1.x

Require variantstring 1.x

## Usage

``` r
check_variantstring_v1(reason = NULL)
```

## Arguments

- reason:

  Passed to
  [`check_suggested_pkg()`](https://plasmogenepi.github.io/PGEcore/reference/check_suggested_pkg.md).

## Value

Invisibly returns `TRUE` if a 1.x version is installed.
