# Validate column types for translate_loci_of_interest inputs

Validate column types for translate_loci_of_interest inputs

## Usage

``` r
validate_translate_column_types(ref_bed, loci_of_interest, allele_table)
```

## Arguments

- ref_bed:

  Panel BED with `ref_seq`.

- loci_of_interest:

  Loci-of-interest table.

- allele_table:

  Allele table.

## Value

Character vector of warning strings (possibly empty).
