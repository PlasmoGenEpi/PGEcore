# PGEcore: Malaria Genomics Analysis Tools

Provides R functions and command-line interfaces for malaria genomics
analysis. Wraps existing specialised tools behind a consistent interface
and shared TSV formats, and adds extra helpers such as naive complexity
of infection (COI), allele frequency and prevalence estimators, filters,
and format converters. Suitable for interactive use, scripting, or as a
shared library in workflow pipelines. Thin wrappers do not install their
specialised dependencies; those must be installed separately when
needed.
