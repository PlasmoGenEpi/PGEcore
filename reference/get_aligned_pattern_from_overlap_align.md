# Aligned pattern sequence including end gaps from an overlap alignment

Aligned pattern sequence including end gaps from an overlap alignment

## Usage

``` r
get_aligned_pattern_from_overlap_align(pw_overlapAlign)
```

## Arguments

- pw_overlapAlign:

  A
  [`pwalign::pairwiseAlignment()`](https://rdrr.io/pkg/pwalign/man/pairwiseAlignment.html)
  overlap result.

## Value

Character string of the pattern with terminal gaps relative to the
subject.
