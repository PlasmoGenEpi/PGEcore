# External MSA binary expected for a given `msa::msa()` method

External MSA binary expected for a given
[`msa::msa()`](https://rdrr.io/pkg/msa/man/msa.html) method

## Usage

``` r
msa_method_binary(msa_method)
```

## Arguments

- msa_method:

  One of `"Muscle"`, `"ClustalW"`, or `"ClustalOmega"`.

## Value

Executable name for
[`check_external_tool()`](https://plasmogenepi.github.io/PGEcore/reference/check_external_tool.md).
