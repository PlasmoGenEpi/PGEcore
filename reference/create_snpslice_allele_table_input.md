# Read an allele table with counts for SNP-Slice

Read an allele table with counts for SNP-Slice

## Usage

``` r
create_snpslice_allele_table_input(
  allele_table_path,
  specimen_name_col = "specimen_name",
  target_name_col = "target_name",
  target_value_col = "aa",
  target_count_col = "reads"
)
```
