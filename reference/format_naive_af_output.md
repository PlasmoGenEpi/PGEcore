# Format naive allele-frequency output for AA or MH input

Format naive allele-frequency output for AA or MH input

## Usage

``` r
format_naive_af_output(out, from_aa)
```

## Arguments

- out:

  Frequency table with `target_name` and `variant`.

- from_aa:

  Logical; `TRUE` when input was amino acid calls.

## Value

Formatted tibble for writing.
