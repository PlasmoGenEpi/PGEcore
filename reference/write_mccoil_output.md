# Write formatted McCOIL output

Write formatted McCOIL output

## Usage

``` r
write_mccoil_output(df_formated, slaf_path, coi_path)
```

## Arguments

- df_formated:

  List from
  [`format_mccoil_output()`](https://plasmogenepi.github.io/PGEcore/reference/format_mccoil_output.md).

- slaf_path:

  SLAF TSV path (`variant`, `freq`).

- coi_path:

  COI TSV path (`specimen_name`, `coi`).
