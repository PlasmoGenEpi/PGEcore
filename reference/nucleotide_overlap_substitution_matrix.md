# Default nucleotide substitution matrix used by pileup and translate

Default nucleotide substitution matrix used by pileup and translate

## Usage

``` r
nucleotide_overlap_substitution_matrix()
```

## Value

A substitution matrix from
[`pwalign::nucleotideSubstitutionMatrix()`](https://rdrr.io/pkg/pwalign/man/substitution_matrices.html).
