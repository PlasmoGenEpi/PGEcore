# Recalculate single-locus prev/freq from multilocus calls (presence/absence)

Recalculate single-locus prev/freq from multilocus calls
(presence/absence)

## Usage

``` r
generate_single_locus_prev_freq_from_multilocus_groups_presence_absence(
  multilocus_calls
)
```

## Arguments

- multilocus_calls:

  Table with `group_id`, `specimen_name`, `variant`.

## Value

Summarized single-locus prev/freq per group.
